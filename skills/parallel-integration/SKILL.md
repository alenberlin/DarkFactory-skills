# Parallel Integration

Use the approved DAG and declared permitted paths. Each implementation attempt receives a source copy of a controller-managed worktree; authoritative Git and other projects are outside its mount. Serialize overlaps and integrate shared contract changes before dependents.

Submit a verified candidate to the coordinator. It constructs the actual three-way merged source, reruns required checks and reviews changes in context before publishing a compare-and-swap reference update under a valid lease. Candidate-only green evidence cannot certify a different merged revision.

On conflict, preserve both candidates and return a scoped diagnosis for repair. Never choose one side silently, force-push, rewrite unrelated history or publish conflict markers. Journal intent before effects and reconcile interrupted operations before retries. Local commits/integration require explicit recorded permission.

Read [the runtime contract](../../docs/RUNTIME_CONTRACT.md) for proposal and authority boundaries and [the operating guide](../../docs/AUTOPILOT.md) for actual commands and compatibility limits.
