# Documentation Delivery

Deliver the PRD, architecture/data/API/design decisions, implementation plan, source, lockfiles, migrations, tests, setup/run instructions, rollback guidance, acceptance matrix and verification/review reports. Use exports from protected runtime records rather than hand-edited success tables.

Execute documented setup and primary flows in a clean approved environment. Describe measured compatibility by host, toolchain and provider version. Separate fixture tests from live agent evidence, and expose unsupported Strict configurations, missing access and unexercised cases.

Keep credentials out of source, examples, logs, memory and delivery archives. Include known limitations and next required operator action. Preserve license/NOTICE attribution. A polished report cannot substitute for a runnable product or final human acceptance.

Read [the runtime contract](../../docs/RUNTIME_CONTRACT.md) for proposal and authority boundaries and [the operating guide](../../docs/AUTOPILOT.md) for actual commands and compatibility limits.
